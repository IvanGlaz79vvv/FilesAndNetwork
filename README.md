Программа учета финансов с отчетностью и интерфейсом командной строки
Описание программы:
Программа предназначена для простого ведения личного финансового учета и позволяет записывать доходы и расходы с последующей возможностью просмотра отчета. Пользователь взаимодействует с программой через простой текстовый интерфейс, выполняя базовые команды. Отчет показывает общую сумму доходов, расходов, баланс и последние пять финансовых операций.

Команды пользователя:
HELP — вывод инструкции по работе с приложением.
REPORT — формирование текущего отчета.
EXIT — завершение работы программы с формированием итогового отчета.
Команда вводится без пробелов и чувствительна к символам пунктуации (;). Все остальные данные считаются новыми операциями.

Формат ввода новых операций:
Операции вносятся строкой следующего формата:


описание; сумма; тип: приход(INCOME)/расход(EXPENSE); дата(день.месяц.год полностью)
Например:


Оплата интернета; 800; EXPENSE; 17.09.2023
Зарплата; 50000; INCOME; 01.10.2023
Содержимое отчета:
Отчёт включает следующие пункты:

Общая сумма всех доходов.
Общая сумма всех расходов.
Баланс — разница между доходами и расходами.
Последние пять выполненных операций с указанием описания, суммы, типа и даты.
Порядок работы с программой:
Запустите программу.
Используйте команды HELP, REPORT или EXIT.
Для добавления новой операции введите её строку согласно описанному формату.
Завершайте сеанс командой EXIT. После завершения автоматически формируется последний отчет.
